A studio catalogue photograph of an impossible gadget: the
YesterKettle™, a brushed-steel kettle with a clock dial on its belly set
to nine o'clock, yesterday. Its spout points up and to the left; below
it sits a full cup, and the tea stream flows *upwards* out of the cup
and back into the spout — yesterday's tea, served today. Plain studio
background, soft floor shadow, spec callouts ("Brews tomorrow, today",
"0 watts — runs on nostalgia", "Pours yesterday's tea — upwards") and a
$299 "Timeless Edition" price tag. The image is a 1024×1024 PNG, drawn
by `render_gadget.py` (Pillow, no network, no randomness) and copied to
`/output/entry.png` by `main.ts`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
